# Security Policy

Thank you for helping us keep this project secure.

## Reporting Security Issues

Please report security vulnerabilities by sending detailed information to
vep-rs@natera.com. Please do **not** report vulnerabilities by filing a
public issue. You can also open a private vulnerability report on GitHub at
https://github.com/natera-open-source/vep-rs/security/advisories/new; only the
maintainers can read it.

We will acknowledge your report, investigate, and keep you informed of the
resolution. Please give us a reasonable opportunity to address the issue before
any public disclosure.
